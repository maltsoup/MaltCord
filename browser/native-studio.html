Native engine and reload behavior
JS, TS, JSX and TSX are compiled by the same esbuild toolchain used by the client. Relative source files are bundled; host aliases reference the existing React, Webpack and API modules. The editor shows syntax diagnostics; semantic checking against a complete checkout remains available through the project TypeScript checks.
Compile does not execute code. Register imports trusted local source into the actual PluginManager registry. Enable waits for native startup, and Disable invokes native stop and declarative resource cleanup. Source patches are applied by the inherited patcher during the next client reload, before Discord modules load. Already applied source patches also need a reload to remove.
